# Internet Speed Test

Консольный скрипт на Node.js: делает 10 последовательных HTTP-запросов к указанному URL, считает среднее время ответа, общий объём скачанных данных и скорость скачивания в Мбит/с.

## Требования

- Node.js 18+

## Запуск

```bash
node index.js <url>
```

Пример:

```bash
node index.js https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
```

Или через npm:

```bash
npm start -- https://example.com/large-file.jpg
```

## Единицы измерения

| Метрика               | Единица                          |
| --------------------- | -------------------------------- |
| Среднее время запроса | мс (миллисекунды)                |
| Общий объём данных    | МБ (1 МБ = 1024² байт)           |
| Скорость скачивания   | Мбит/с (Mbps), 1 Mbps = 1e6 байт |
